COMPARE 02 / 06
HOW TO ROTATE

左旋 · 右旋
怎么操作

心智模型

旋转名字看哪边孩子升上来：
左旋 = 右孩子升；右旋 = 左孩子升。
中间子树 β 要搬家，才能保住 BST 有序。

左旋 Left Rotate(P)

R 升为新根 · P 降为 R 的左孩子 · β 改挂到 P.right
R=P.right → P.right=β → R.left=P

右旋 Right Rotate(P)

L 升为新根 · P 降为 L 的右孩子 · β 改挂到 P.left
L=P.left → P.left=β → L.right=P
中序不变 · BST 性质保留 03 / 06
FOUR CASES

四种失衡
怎么选旋转

在左旋 / 右旋之上，用插入路径判断。
单旋纠直链，双旋先拧直。

LL
右旋

左左偏 → Right(P)

插入落在左孩子的左子树。
对失衡点做一次右旋即可。

RR
左旋

右右偏 → Left(P)

插入落在右孩子的右子树。
对失衡点做一次左旋即可。

LR
左右双旋

折线 → Left(L) 再 Right(P)

插入落在左孩子的右子树。
先拧成 LL，再右旋失衡点。

RL
右左双旋

折线 → Right(R) 再 Left(P)

插入落在右孩子的左子树。
先拧成 RR，再左旋失衡点。

口诀：失衡方向 = 插入路径的前两步

RULES 05 / 06
WHY STD::MAP

为什么 map
用红黑树

ONE LINE

map / set 写操作频繁
红黑树用更松的平衡，换更少的旋转次数。
不是 AVL 不行，是工程折中。

01

写多，怕旋转放大

插入删除是常态。红黑树插入最多约 2 次旋转；AVL 删除可能沿路径多次旋转。

02

存储更轻

红黑树大约 1 bit 颜色；AVL 通常要存平衡因子或高度字段。

03

有序能力不丢

旋转保中序，BST 仍成立。lower_bound、区间遍历照样可用。

04

什么时候仍想 AVL

查找远多于写入、对最坏高度更敏感时，AVL 的「更矮」才是优势。
