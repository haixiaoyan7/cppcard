01
核心
CORE

内存池的核心思想是：提前申请一大块内存，
将其切分成固定大小的 Block，
通过 Free List 复用，
避免频繁调用 new/delete。

02
切块组链
CHUNK

用 vector 保存每次申请的 Chunk 地址。
申请新 Chunk 后，按照 block_size
和 block_num 切分成多个 Block，
每个 Block 通过 next 指针连接成 Free List。

03
分配归还
ALLOC

allocate()：Free List 为空则
先申请并切分新 Chunk；
然后摘下链表头，返回这块未初始化内存。
deallocate()：把头插回 Free List，
不还给操作系统。

04
清空
CLEAR

clear()：按 vector 里的地址
对每个 Chunk 做 operator delete，
清空 vector，free_list 置空。

05
对齐
ALIGN

align_up 用于将地址或大小
向上调整到指定 alignment 的整数倍，
保证 Block 满足内存对齐要求。

★
一句话总结
SUMMARY

提前切块、Free List 复用；
allocate 摘头、deallocate 头插，clear 才还给系统。
