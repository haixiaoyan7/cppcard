#085
数据库与分布式 DATABASE
INTERVIEW ANSWER
参考回答
01
穿透
MISS

缓存穿透是指查询的数据
在缓存和数据库中都不存在，
例如恶意请求不存在的 ID，
导致每次请求都绕过缓存直接访问数据库。

02
穿透方案
FIX

布隆过滤器，提前判断数据是否可能存在；
数据库查不到时缓存一个短 TTL 的空值；
参数校验，拦截明显非法请求；
限流，防止恶意刷接口。

03
击穿
HOTKEY

缓存击穿是指一个热点 Key
在高并发访问时刚好过期，
导致大量请求同时 Miss，一起访问数据库。

04
击穿方案
FIX

互斥锁，只允许一个线程重建缓存；
逻辑过期，不设置物理 TTL，在 value 中保存过期时间
热点 Key 设置较长 TTL 或不设置过期时间，
并通过后台定时刷新。

05
雪崩
AVALANCHE

缓存雪崩是指大量 Key 同时过期，
或者 Redis 整体不可用，
导致大量请求同时访问数据库，甚至拖垮整个系统。

06
雪崩方案
FIX

TTL 加随机值，避免大量 Key 同时过期；
Redis 主从、哨兵或集群，提高缓存可用性；
多级缓存；限流降级和熔断，保护数据库；

★
一句话总结
SUMMARY

穿透是查无数据打穿 DB；
击穿是热点过期并发打库；
雪崩是批量过期或缓存不可用。
