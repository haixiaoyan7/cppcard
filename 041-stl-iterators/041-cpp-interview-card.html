STL 与数据结构 STL

参考回答
01
设计本质
ESSENCE

迭代器是连接容器和算法的桥梁，
本质上是对元素访问方式和遍历能力的抽象；
算法只依赖迭代器能力，不依赖具体容器。

02
输入与输出
INPUT / OUTPUT

Input Iterator 支持单向、单遍读取，
例如 istream_iterator；
Output Iterator 支持单遍写入，
例如 ostream_iterator 和 back_inserter。

03
前向与双向
FORWARD / BIDIR

Forward Iterator 支持单向、多遍遍历，
例如 forward_list 和无序容器；
Bidirectional Iterator 进一步支持 --，
例如 list、set 和 map。

04
随机与连续
RANDOM / CONTIG

Random Access Iterator 支持 +、-、[] 和随机跳转，
例如 vector、deque；
C++20 Contiguous Iterator还保证元素连续，
例如 vector、array 和 string。

05
解耦思想
DECOUPLING

容器负责存储，迭代器负责访问，算法负责处理；
算法面向能力编程，因此同一算法可以复用于
所有满足最低迭代器要求的容器或数据源。

★
一句话总结
SUMMARY

迭代器用分层能力统一访问接口，
从而让容器与算法彼此解耦、自由组合。
