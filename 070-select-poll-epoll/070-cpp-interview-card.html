#070
网络编程与操作系统 NETWORK
INTERVIEW ANSWER
参考回答
01
句柄
HANDLE

网络编程通过 Socket创建文件描述符（FD）。
FD 是内核提供给用户层的句柄，
用户层通过它调用 read()、write()、
recv()、send() 等接口与内核交互。

02
核心差异
KEY DIFF

select、poll、epoll 的核心差异是：
如何保存关注的 FD，
以及如何找到就绪的 FD。

03
select
BITMAP

使用 fd_set 位图保存关注的 FD。
调用前设置关注，内核返回时修改位图，
用户层需要遍历整个 FD 范围查找就绪 FD。
常见实现的 FD_SETSIZE 为 1024，
因此存在 FD 值范围限制。

04
poll
ARRAY

使用 pollfd 结构体数组保存 FD，
并通过两个字段表示关注事件和实际就绪事件。
它没有 select 的固定大小限制，
但每次调用仍需遍历整个数组。

05
epoll
KERNEL

关注的 FD 保存在内核中，主要使用：
红黑树管理关注的 FD，就绪链表保存已经就绪的 FD。
通过 epoll_ctl() 管理 FD，操作通常为 O(log N)；
epoll_wait() 直接获取就绪事件，
成本主要与就绪数量 K 有关，通常为 O(K)。

★
一句话总结
SUMMARY

核心是怎么存关注、怎么找就绪；
epoll 在内核用红黑树加就绪链表，wait 跟 K 走。
