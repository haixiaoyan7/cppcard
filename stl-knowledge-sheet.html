01
容器
Container · 存数据
序列式·线性排列
array 连续定长 · 无 insert
vector 连续可变 · 尾插均摊 O(1)
deque 中控+block · 头尾 O(1)
list 双向链 · 用成员 sort
forward_list 仅 next · after
随机访问 arr/vec/deq list/fl
关联式 · 红黑树
有序 · 查找插入删除 O(log n)
set / map key 唯一
multi* 允许重复 key
map 存 pair<const Key, T>
支持 lower / upper_bound
要有序 / 范围 → map
无序关联 · 哈希
均摊 O(1) · 最坏可退化 O(n)
冲突多用链地址法
负载因子过大 → rehash
key 需可哈希 + 可相等
还有 unordered_multi*
只要快查 → unordered
选型 默认 vector 头尾 deque 中部 list 有序 map/set 快查 unordered
02
迭代器
Iterator · 容器与算法的桥梁
分类 · 能力递进
In→ Out→ Fwd→ BiDir→ Rand→ Contig
算法认迭代器能力，不认具体容器
std::sort 需随机访问
list 用成员 sort，不能用 std::sort
Contig：vector/array/string，非 deque
失效规则
vector扩容全失效；中间插删 → 该点之后
deque中间可能全失效；两端影响端迭代器
list / fl仅被删节点失效
map / set删谁失效谁
unordered删谁失效谁；rehash 则全失效
